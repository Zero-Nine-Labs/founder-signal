# Audit delivery

Keep the report concise and usable. Scale detail to the findings; do not force empty sections. Once the goal is established, the audit includes all six profile sections and all four copy deliverables, including a retain-as-is recommendation where appropriate. If the goal is missing, follow the clarification-only stop in SKILL.md instead.

## Current profile

State the founder, target URL, primary goal, intended audience, rubric version and evidence date/source. Label live retrieval, supplied material and previous audit evidence accurately.

Use the calculator-generated score block unchanged: summary, six section rows, full maxima and total row. Keep its start/end comments and verify the exact report before delivery using the procedure in [scoring.md](scoring.md). Do not repeat current totals in other prose or the delivery message. If execution is unavailable, state that the numeric score is unavailable and deliver a qualitative audit.

Outside the generated block, keep enough criterion evidence, statuses and reasons in the report or a requested attachment to explain every judgement and unassessed check. Unknown awards stay unknown. If statuses change, regenerate and verify again.

Summarise whether a new reader can understand the offer, credibility and next step. Show any material factual issue next to the score.

## Fixes

List fixes in priority order. Each includes:

- Section and criterion IDs.
- Current evidence and observed problem.
- Consequence for the founder's audience/goal.
- Recommended action, priority and approximate effort.

Include both fixable gaps and the evidence needed to resolve unassessed checks. Do not claim an unseen section is empty.

## Replacement copy

Provide separate, clearly labelled blocks for:

1. Recommended headline. Add an alternative only when it offers a useful choice.
2. Complete About section with an appropriate next step.
3. Banner wording and a short placement brief for desktop/mobile.
4. Current founder-role Experience description.

Recommend the Featured items and order using existing, approved assets. If none exists, specify useful assets to create rather than inventing links or customer results. Mark this as a content gap.

Preserve ownership, role scope, dates, proof, attribution and uncertainty. Do not manufacture superiority claims, revenue, customers, investor backing or experiences. Use plain language and the founder's established voice.

Distinguish copy ready to use from copy requiring a missing fact, permission or verification. A placeholder is a pending draft, not an approved statement. Keep scoring commentary outside the public-facing copy.

## Comparison when available

For the same founder and rubric, show previously assessed and currently assessed criteria, verified changes and remaining gaps. Highlight any changed goal or coverage that affects comparability. Only label a score current after observing the changed profile. A hypothetical improvement can be explained as a proposed benefit; it cannot replace the current score.

If the user requests a numerical projection, score only the criteria changed by the proposed copy against the same brief. Carry every unchanged award and unassessed check forward, including visual/layout checks. Show it separately as a draft projection with assumptions, using the same range arithmetic. It is not a new audit, a verified improvement or a final grade.
